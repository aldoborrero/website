<h1>I'm Aldo, a consultant at Numtide. I build the infrastructure coding agents run on, mostly with Nix, and write about what I learn along the way.</h1>

I've worked with LLMs since 2023, and I build my own agent tools, like [ccq](https://github.com/aldoborrero/ccq), which searches across Claude Code history. Before that I spent years in Ethereum: I led [EthVM](https://github.com/EthVM/EthVM), the open-source block explorer, for MyEtherWallet, I help maintain [ethereum.nix](https://github.com/nix-community/ethereum.nix), and I co-founded 41North. Earlier I worked at Mobile Jazz and ING, and I started out writing Android apps.
